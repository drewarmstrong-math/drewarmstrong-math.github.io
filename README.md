# Drew Armstrong website

This is a static HTML website. It works both when opened directly from Finder
and when published by GitHub Pages. No PHP, Jekyll, or build step is required.

## Updating the menu

Edit only the `menuItems` list near the top of `menu.js`. Each item has a link,
label, and color class. Save the file and reload any page to see the new menu.

Do not copy menu markup into the individual HTML pages. Every page uses the same
`menu.js` file.

## Adding PDFs

Place each PDF at the relative path used by its link. See the separately supplied
`pdf-files-needed.txt` inventory for the document paths omitted from the archive.
